Google Apps Script Terbaru (Code.gs)

Salin ke Extensions → Apps Script, jalankan setupSheets() sekali, pasang trigger waktu untuk syncMarketPrices, lalu Deploy sebagai Web App (Access: Anyone). Bila sudah pernah deploy, pilih New version. Opsional: isi API_TOKEN dan tambahkan ?token=... pada URL di aplikasi.

Reset Data Portofolio?

Tindakan ini mengembalikan profil, instrumen awal, riwayat transaksi, dan snapshot ke data bawaan (demo). URL Google Apps Script dan harga terakhir tetap dipertahankan. Baris di sheet Trades tidak ikut terhapus.
